Daimler Truck AG · Digital Solutions, Mercedes-Benz Trucks

ApiCon — Master Data Validation

Automated product data validation across up to 25 European markets.

In production use

The problem. Before each market rollout, product data for digital truck services had to be checked manually against an Excel reference. This took roughly an hour per market and depended on a single person at headquarters.

My contribution. I owned the requirements and scoring logic, co-designed the architecture with AI coding agents and developed a Python/Flask application, which I rolled out to 15 users. It compares reference and API values, classifies deviations by business impact and generates an Excel report for review and correction.

  • ~90% less validation time compared with manual checks
  • 5–8 min per market, down from roughly 60 minutes
  • 15 users working with the tool in Germany and India
  • Up to 25 European markets supported

How it works

  1. 1 Upload the Excel master data that serves as the reference source.
  2. 2 The tool queries the live product API for all selected markets in parallel.
  3. 3 Reference and API values are compared field by field; deviations are classified by business impact.
  4. 4 A multi-sheet Excel report supports review and correction; stored runs enable history and delta comparisons.
  • Python
  • Flask
  • REST APIs
  • SQLite
  • pandas
  • pytest

Developed with Claude Code and Codex. A separate development team in India has requested the application to adapt it to its own use case. ApiCon is also the subject of my Design Science Research project at DHBW Stuttgart.

Independent full-stack project · Rental operations

Apartment Rental Platform

One workflow for rental enquiries, reservations, contracts and move-out.

Completed · launch pending

The brief. A private landlord with eight apartments and a seven-room shared flat needed one place to manage availability, enquiries, documents and deadlines.

My contribution. I developed the public website and management dashboard with AI coding agents, using Python, Django and PostgreSQL. The application covers the entire process from availability check to move-out, with double-booking protection, automated emails and around 700 automated tests. Development is complete; launch is pending.

  • 8 apartments plus a seven-room shared flat
  • 5-day holds temporary reservations after preliminary approval
  • ~700 tests automated tests, including double-booking protection
  • 2FA two-factor authentication for administrator access

From enquiry to move-out

  1. 1 A server-validated enquiry checks availability and prevents overlapping bookings.
  2. 2 Preliminary approval creates a five-day hold and sends the document checklist.
  3. 3 The dashboard guides review, acceptance, rental status and all follow-up actions.
  4. 4 Scheduled jobs handle emails, deadlines and data deletion according to retention rules.
  • Python
  • Django
  • PostgreSQL
  • HTML & CSS
  • pytest
  • 2FA / TOTP

Double-booking protection is enforced at database level. Retention rules, an append-only audit trail and idempotent email processing support day-to-day administration.
